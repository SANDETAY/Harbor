# Bookmarks — websites Harbor needs

Two files:

| File | Use |
|------|-----|
| [**BOOKMARKS.md**](./BOOKMARKS.md) | Full list with notes (read in editor) |
| [**open-bookmarks.html**](./open-bookmarks.html) | Pretty clickable page — open in browser |

## Recommended browser folder

1. Open `open-bookmarks.html`  
2. Create a bookmark folder named **Harbor**  
3. Star every link into that folder (grouped sections match the page)

You only need to do this once.
