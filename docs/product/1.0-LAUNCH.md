## What’s “1.0 complete” for this ship

Harbor is a **calm, on-device life app** (tasks, Life, streaks, Harbor Day, PWA + Capacitor).  
1.0 means: real daily use is solid, TestFlight/Play-ready, privacy-honest, no required cloud.

### Explicitly *not* in 1.0

| Item | Why later |
|------|-----------|
| **Cloud backup & multi-device sync** | Next phase — backend, auth, conflict rules |
| Real wearables / HealthKit metrics sync | Never ship fake |
| Social / sharing tasks with friends | Scope creep |
| Ads | After retention is proven |

## Next phase: backend backup & sync

When starting backend work, prefer:

1. **Export format already used** for local backup (same JSON profile schema)
2. **Auth** (Apple / Google) only if needed for multi-device
3. **Sync model:** last-write or CRDT-lite for lists; never silent cloud overwrite of local without UX
4. **Privacy:** end-to-end or server-encrypted blobs; document in `privacy.html`
5. Keep **fully offline** path as default; cloud is opt-in

## Ship checklist (before store “Ready for Sale”)

1. Archive **build ≥ 400** · TestFlight smoke  
2. Confirm widgets update after open app once  
3. Privacy URL live · support email works  
4. Screenshots match current UI (Brief, Task, Life, Harbor Day)  
5. Free vs Pro story matches `docs/FREE-VS-PRO.md`
