Harbor · Local-first · Optional cloud

Privacy Policy

Last updated: July 30, 2026 · Also see repository docs/PRIVACY.md.

Harbor is a calm life-management app. By default it is local-first: your plans live on your device. No ads. We do not sell personal data. An account is optional — only if you use Account & cloud.

Data on your device

Tasks (including Morning / Evening lists), energy preference, streaks, bills, groceries, subscriptions, local household color tags, calendar events you create or import, calendar feed URLs, themes, and optional profile fields are stored in on-device storage (for example browser local storage or app storage). Clearing site data, uninstalling, or losing a device without a backup can erase this data.

Optional Account & cloud

If you open Account & cloud and sign in (when the app is configured with a backend), Harbor may use a hosted service (Supabase) for:

  • Sign-in with Apple, Google, or email and password
  • Optional backup snapshots you choose to push or pull
  • Optional household membership and invite codes (sharing structure — not automatic full task sync of everything on your phone)
  • Optional Google Calendar connect (Pro) when you link it — read-only calendar events for Schedule

If you never sign in, this path is unused. Export / Import Profile files still work fully offline and you choose who receives them.

What may leave your device

  • Weather: if you allow location, approximate location may be sent to a forecast provider (such as Open-Meteo).
  • Calendar URL: Harbor fetches feeds directly from the calendar host by default. A network helper (third-party proxy) is off unless you enable it in Settings; if enabled, that helper may see the full feed URL. Prefer Import file (.ics) for maximum privacy.
  • Device calendars (store app): read on-device calendars so Schedule can match appointments; event copies stay on the device.
  • Camera / mic: only when you use recipe photo or voice features; not used for ads.
  • Local reminders (store app): scheduled on the device; no remote push server for those alerts.
  • Feedback: messages you send may go through a feedback delivery service. Do not include secrets.
  • Hosting / updates: loading the web app or store updates may create ordinary server or CDN logs under those providers’ policies.
  • Cloud account path: only when you sign in — auth and any snapshots/household records you create with the backend provider.

Sharing with others

Profile export creates a file on your device; you choose how to share it. Household invites (when cloud is enabled) use invite codes you create. Local household color tags on Schedule are separate and stay on device unless you also use cloud household features.

Children

Harbor is not directed at children under 13.

Changes

If we expand cloud sync, change calendar networking defaults, or change what household sharing includes, we will update this policy before those changes ship.

Contact

Use in-app Feedback, or the support contact on the App Store / Play listing when published.
